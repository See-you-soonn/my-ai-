

مستودع متكامل يحتوي على **وكلاء ذكاء اصطناعي جاهزين للإنتاج (Production-Ready AI Agents)، وأنظمة استرجاع المعلومات (RAG Pipelines)، وسلاسل أتمتة معقدة** لتطوير العمليات التشغيلية، تحليل البيانات، إدارة الموارد البشرية، والربط الذكي بين الأنظمة.

---

## 🌟 المجلدات الرئيسية والأقسام التقنية

### 1. 🔍 وكلاء البحث والتحليل واسترجاع البيانات (RAG & Data Analysis)
* **أنظمة RAG ذاتية التحسين:** مخصصة للاستعلام من المستندات وإعادة الترتيب الدلالي (Semantic Re-ranking) باستخدام **Qdrant**, **Mistral AI**, و **OpenAI**.
* **أدوات كشط وتحليل الويب التلقائية:** استخراج وتحليل بيانات مقاطع YouTube، مناقشات Reddit، مراجعات Trustpilot، والنصوص الخام.
* **معالجة الفواتير والبيانات المالية:** وكلاء ذكاء اصطناعي لمطابقة الحسابات المالية (Reconcile Payments) واستخراج البيانات غير المنظمة وتحويلها لتنسيقات هيكلية (CSV/Database).

### 2. 🗄️ وكلاء قواعد البيانات والتحويل الذكي (Database & NL2SQL)
* واجهات استعلام باللغة الطبيعية لتحويل الأوامر إلى ألتصاميم SQL مباشرة وتطبيقها على قواعد البيانات: **PostgreSQL**, **SQLite**, **MongoDB**, و **Supabase Vector Search**.
* معالجة الأوامر المعقدة مع تطبيق معايير أمان عالية لمنع الاستعلامات الضارة.

### 3. 👥 أتمتة الموارد البشرية والتوظيف (HR & Recruitment)
* **نظام التقييم والفرز التلقائي للسير الذاتية:** مسارات عمل عبر **n8n** مدمجة مع **OpenAI** لتقييم ملاءمة المتقدمين للوظائف وحساب درجات المقابلة.
* **ربط BambooHR والمساعد الصوتي:** مساعد ذكي يستجيب لسياسات الشركات عبر **BambooHR API** ومزود بتقنية Whisper لتحويل الصوت إلى نص.

### 4. 📬 أتمتة البريد الإلكتروني وأنظمة إدارة العملاء (Email & CRM)
* **المصنف الذكي للبريد الإلكتروني:** أتمتة خدمات **Gmail & Outlook** لقراءة وتحليل المرفقات (PDF OCR) وتوليد ردود مخصصة.
* **مزامنة أنظمة CRM:** مسارات عمل متعددة المراحل تربط بين الـ Webhooks ورسائل الاستفسارات مع **HubSpot**, **Airtable**, و **Notion**.

### 5. 🤖 وكلاء التواصل الاجتماعي والبنية التحتية (Multi-Channel Bots & DevOps)
* وكلاء ذكاء اصطناعي تفاعليين لإدارة التواصل عبر منصات **Slack**, **Telegram**, و **WhatsApp**.
* إدارة وإعادة تشغيل البنية التحتية باستخدام **Docker Compose Controllers** و **Linux Webhooks**.

## 🛠️ التقنيات وأدوات التطوير (Tech Stack)

* **الأتمتة وإدارة مسارات العمل:** n8n, Make, LangChain, Python Scripts.
* **نماذج الذكاء الاصطناعي والرؤية:** OpenAI GPT-4o, Google Gemini Flash/Vision, Mistral AI, HuggingFace.
* **قواعد البيانات والبحث المتجهي:** Qdrant, PostgreSQL, Supabase, SQLite, Airtable.
* **الربط والبنية التحتية:** Docker, Webhooks, REST APIs, Git, Linux.
